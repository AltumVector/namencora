# Axioms — Project Rules

1. **Zero Thin Content:** Никаких пустых карточек на продажу доменов. Каждое имя — это спецификация реального инженерного паттерна или протокола.
2. **Entity Monopoly:** Использование имен без суффикса `.com` в текстах закрепляет сущность в Google Knowledge Graph и AI-моделях. Прямое владение доменом `.com` делает ресурс первоисточником.
3. **Append-Only Architecture:** Каждая новая сущность добавляется изолированно в `specs/` без переписывания ранее созданных блоков.
4. **Source of Truth:** Терминал, репозиторий и локальное хранилище Obsidian являются постоянной памятью; диалог — лишь вычислительный процессор.
5. **36-Параметрическая валидация:** Ни один актив не публикуется без прохождения контроля по 4 векторам качества.
